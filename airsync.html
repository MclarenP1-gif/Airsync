A canvas. Any device.

  1. Open this page on your computer in Host canvas mode.
  2. Open the same page on your phone and scan the host QR code, or choose Touch pad and enter its pairing code.
  3. Draw with a finger or stylus. Both devices see the same board. Landscape gives your phone more drawing room.

Undo and redo change the shared board for everyone. Clear can also be undone. Finish all strokes before using these controls. Keep the host tab open; refreshing or closing it ends the session and discards the board.

For QR pairing, publish this one file on GitHub Pages or Cloudflare Pages. A file:// or localhost address cannot be opened from another device; open the file on both devices and enter the code manually instead, if their browsers allow local HTML.

Pairing requires internet access to the CDNs and the free PeerJS signaling service. Drawing travels over encrypted WebRTC. Use the same Wi-Fi for the best chance of a direct connection. Isolated Wi-Fi, VPNs, or strict firewalls may block it. This file includes STUN, but no TURN relay or uptime guarantee.
